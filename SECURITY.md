# Security Policy

## Reporting Security Issues

The KUDO maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/kudobuilder/kudo/security/advisories/new) form.

For more details, see the [KUDO security policy](https://github.com/kudobuilder/kudo/blob/main/SECURITY.md).
